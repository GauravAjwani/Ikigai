Ikigai · decision memory for Slack

How Gemini is wired

Slack text never goes to Gemini as a prompt. It is wrapped as untrusted notes, ranked in memory, then discarded. FastAPI on Cloud Run is the only google.genai client. A security edge sits in front of every hop.

Who talks to whom

Gemini is a backend RPC. Slack text reaches it only as untrusted notes. It has no session to the UI or Firestore.

Request path

  1. 1Guard: Slack HMAC, Cloud Run API token, drop Events API retries. Then /api/run, /slack/*, or /mcp/*.
  2. 2Prefilter drops chatter with no model. Watcher gate uses Flash-Lite on untrusted text. Commands skip the gate.
  3. 3Cheap probes are heuristic — no Gemini. Retrieve Slack + Firestore, then pack thread notes.
  4. 4embed() ranks in memory and drops vectors. Flash lookup reads notes only. Never a raw Slack quote.
  5. 5FastAPI writes derived labels to Firestore and returns a card. Gemini never sees the database.
