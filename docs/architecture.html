How Gemini is wired

The frontend never calls Gemini. Slack never calls Gemini. Firestore never calls Gemini. One backend process — FastAPI on Cloud Run — is the only client of google.genai. Sage arrows are the only Gemini path. The dashed line is the missing Gemini→Firestore session.

Request path

  1. 1Replay posts POST /api/run. Slack posts /slack/commands or /slack/events. MCP posts /mcp/query_decisions.
  2. 2Prefilter drops chatter with no model. Gate uses Flash-Lite. About 95% of watcher traffic exits here.
  3. 3Flash-Lite writes cross-vocabulary probes. Retrieve fans out to live Slack search and the Firestore label graph.
  4. 4embed() ranks candidates in memory, then drops the vectors. Flash adjudicates same / current / reversed / concurrent.
  5. 5FastAPI writes derived labels to Firestore and returns a card to Replay or Block Kit to Slack. Gemini never sees the database.
